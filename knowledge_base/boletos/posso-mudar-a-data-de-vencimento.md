# Posso mudar a data de vencimento do boleto?

A data de vencimento é definida pelo contrato coletivo e vale para todos os beneficiários do mesmo grupo, por isso não pode ser alterada individualmente.

## Se o vencimento é um problema

Você pode pagar antes do vencimento a qualquer momento. Se estiver com dificuldade de pagamento, um atendente pode verificar as opções de negociação disponíveis.
